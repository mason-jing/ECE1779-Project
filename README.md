# PathWise: Cloud Native Job Market Intelligence Platform

Course: ECE1779 

Students and career explorers need to understand employer expectations when choosing a career direction, planning their learning, and selecting projects. Relevant requirements are spread across company recruitment websites and described in varying formats. Comparing skills, experience, education, and responsibilities requires repeated collection and manual organization as listings change.

Research on skill extraction shows how unstructured job postings can inform analysis of employer demand. It also identifies coverage limitations in predefined skill inventories, particularly as new skills emerge [1]. For users comparing career directions, organizing requirements consistently and retaining supporting sources are therefore important parts of interpreting recruitment information.

PathWise collects and analyzes public job postings from selected employers hiring in Canada. It helps users compare career directions, understand common requirements, and consider which skills or experiences to develop. For example, a student choosing between Backend and Data roles can compare requirements across the same employers and use the findings to guide a course or project choice. Source links allow users to inspect the postings behind each comparison.
